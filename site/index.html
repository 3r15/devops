14단계를 성격에 따라 다섯 파트로 묶었습니다. 각 파트 안에서는 순서대로 진행하는 것을 권장합니다.

🧱

Part 1. 기반 다지기

리눅스, 네트워크, 버전 관리. 모든 DevOps 작업이 올라서는 바닥입니다.

리눅스 · 네트워크 기초 · 깃과 깃허브~54h ⚙️

Part 2. 자동화의 언어

반복을 없애는 도구. Bash로 시스템을 다루고 Python으로 확장합니다.

셸 스크립팅 · 파이썬 기초~36h 📦

Part 3. 서비스와 컨테이너

애플리케이션을 실제로 띄우고, 패키징하고, 오케스트레이션합니다.

웹 서버 · 도커 · 쿠버네티스~66h 🚀

Part 4. 배포와 인프라

파이프라인으로 배포하고, 코드로 인프라를 정의하고, 클라우드에 올립니다.

CI/CD · 코드형 인프라 · 구성 관리 · 클라우드~82h 🛡️

Part 5. 운영과 보안

돌아가는 시스템을 관찰하고, 지키고, 오래 살아남게 만듭니다.

모니터링과 로깅 · 보안~38h

전체 단계

Stage 01 Linux 파일시스템, 권한, 프로세스, 패키지, systemd — 서버 위에서 손이 자유로워지는 단계. 완료 Stage 02 Networking Fundamentals OSI/TCP-IP, IP·서브넷, DNS, HTTP, 방화벽. 장애의 절반은 네트워크에서 시작됩니다. 완료 Stage 03 Git + GitHub 브랜치 전략, 리베이스/머지, PR 리뷰, 태그와 릴리스. 완료 Stage 04 Shell Scripting (Bash) 파이프라인, 조건/반복, 함수, set -euo pipefail, 실전 운영 스크립트. 완료 Stage 05 Python (Basics) 자료구조, 파일·프로세스 다루기, requests, 가상환경, 간단한 자동화 CLI. 완료 Stage 06 Web Servers (Nginx / Apache) 리버스 프록시, 가상 호스트, TLS, 로드밸런싱, 정적 자원 서빙. 완료 Stage 07 Docker 이미지·레이어, Dockerfile 최적화, 볼륨/네트워크, Compose. 완료 Stage 08 Kubernetes Pod·Deployment·Service·Ingress, ConfigMap/Secret, 헬스체크, Helm 맛보기. 완료 Stage 09 CI/CD (GitHub Actions / Jenkins) 빌드-테스트-배포 파이프라인, 아티팩트, 시크릿, 환경별 배포 전략. 예정 Stage 10 Infrastructure as Code (Terraform) HCL, state, provider/module, plan-apply 워크플로, 드리프트 관리. 예정 Stage 11 Configuration Management (Ansible) 인벤토리, 플레이북, 롤, 멱등성, 시크릿(vault). 예정 Stage 12 Cloud Platforms (AWS / Azure / GCP) IAM, 컴퓨트, 네트워킹(VPC), 스토리지, 매니지드 서비스, 비용 관리. 예정 Stage 13 Monitoring & Logging Prometheus 메트릭, Grafana 대시보드, ELK 로그 파이프라인, 알럿 설계. 예정 Stage 14 Security (DevSecOps Basics) 최소 권한, 시크릿 관리, 취약점 스캔, 공급망 보안, 파이프라인 내 보안 게이트. 예정

이 사이트를 쓰는 법

1. 읽는다

각 단계는 개념 설명 → 명령어/코드 → 자주 하는 실수 순서로 이어집니다.

2. 따라 친다

모든 예제는 복사해서 바로 실행할 수 있는 형태입니다. 눈으로 읽지 말고 쳐보세요.

3. 체크한다

단계 하단의 체크리스트는 브라우저에 저장됩니다. 끝낸 항목을 표시하며 진행하세요.
