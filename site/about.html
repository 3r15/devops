About

이 사이트에 대하여

DevOps를 처음부터 훑고 싶은 사람이 순서대로 따라갈 수 있도록 만든 학습 사이트입니다.

무엇인가요

14단계 커리큘럼을 다섯 파트로 묶어 정리한 정적 사이트입니다. 각 단계는 개념 → 실습 → 체크리스트로 이어지며, 읽기만 해서는 넘어갈 수 없도록 손으로 확인하는 과제를 함께 둡니다.

어떻게 만들어졌나요

빌드 도구나 프레임워크 없이 순수 HTML/CSS/JS로 되어 있습니다. 커리큘럼 구조는 data/curriculum.json 한 곳에서 관리하고, 메인·파트 페이지는 tools/scaffold.py가 그 데이터로부터 생성합니다. 단계 본문은 사람이 직접 씁니다.

배포는 GitHub Actions가 main 브랜치의 site/ 디렉터리를 그대로 GitHub Pages로 올립니다.
